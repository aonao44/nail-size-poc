# ネイルチップサイズ測定ツール PoC 要件定義書

## 0. プロジェクト概要

スマホカメラで爪を撮影し、500円玉を基準スケールとして爪の寸法を推定、適切なネイルチップサイズを提案するWebツールのPoC版を実装する。

- **対象形状:** ショートオーバル（1種類）
- **想定ユーザー:** ネイルチップ購入検討者
- **想定アクセス:** 数十〜数百人/日
- **形態:** 単体Webページ（ECサイト連携なし）
- **開発期間:** 3日間

## 4. サイズデータ仕様

### 対象：ショートオーバル（PoC）

```typescript
// lib/sizeData.ts
export const SHORT_OVAL_SIZES = [
  { size: 0, length: 20,   width: 13,  innerCurve: 16.5 },
  { size: 1, length: 19,   width: 12,  innerCurve: 15   },
  { size: 2, length: 18,   width: 11,  innerCurve: 13.5 },
  { size: 3, length: 17,   width: 10,  innerCurve: 12   },
  { size: 4, length: 16,   width: 9,   innerCurve: 11.5 },
  { size: 5, length: 15,   width: 8.5, innerCurve: 11   },
  { size: 6, length: 14.5, width: 8,   innerCurve: 10.5 },
  { size: 7, length: 14,   width: 7.5, innerCurve: 9    },
  { size: 8, length: 14,   width: 7,   innerCurve: 8    },
  { size: 9, length: 13,   width: 6,   innerCurve: 7.5  },
];
// 単位: mm
// length = 長さ（外側カーブ）
// width = 幅（直線）
// innerCurve = 幅（内側カーブ）※PoCでは未使用
```

### マッチングロジック

```typescript
// lib/matchSize.ts
// 幅を主、長さを副として、加重距離が最小のサイズ番号を返す
export function matchSize(estimatedWidth: number, estimatedLength: number) {
  const weighted = SHORT_OVAL_SIZES.map(s => {
    const widthDiff = Math.abs(s.width - estimatedWidth);
    const lengthDiff = Math.abs(s.length - estimatedLength);
    // 幅を優先（重み2）、長さ（重み1）
    const score = widthDiff * 2 + lengthDiff * 1;
    return { ...s, score };
  });
  weighted.sort((a, b) => a.score - b.score);
  return weighted[0];
}
```

## 5. Gemini API 連携仕様

### 5-1. API Route（サーバーサイド）

`app/api/estimate/route.ts`

- クライアントから base64 エンコードされた2枚の画像を受け取る
- Gemini Vision API を呼び出し、推定値をJSONで受け取る
- レスポンスをクライアントに返す

### 5-2. プロンプト例

```typescript
// lib/geminiPrompt.ts
export const ESTIMATION_PROMPT = `
あなたは画像解析の専門家です。以下の2枚の画像を解析してください。

【画像1】爪を真上から撮影した画像。500円玉が爪の横に配置されています。
【画像2】爪を真横から撮影した画像。500円玉が爪の横に配置されています。

【基準情報】
- 500円玉の直径: 26.5mm

【タスク】
1. 画像1から、500円玉のピクセル数を測定し、そのピクセル-mm比率を算出してください。
2. 同じ比率を使って、爪の横幅（直線）をmmで推定してください。
3. 画像2から、爪の長さ（外側カーブ、爪の根本から先端までの曲線に沿った長さ）をmmで推定してください。

【出力形式】
以下のJSON形式のみで回答してください。説明文は一切不要です。

{
  "width_mm": <数値>,
  "length_mm": <数値>,
  "confidence": <0〜1の信頼度>,
  "notes": "<測定上の注意点があれば記載>"
}
`;
```

### 5-3. 呼び出し例

```typescript
// app/api/estimate/route.ts
import { GoogleGenerativeAI } from "@google/generative-ai";

const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY!);

export async function POST(req: Request) {
  const { imageTop, imageSide } = await req.json();

  const model = genAI.getGenerativeModel({
    model: "gemini-2.0-flash",
    generationConfig: { responseMimeType: "application/json" }
  });

  const result = await model.generateContent([
    ESTIMATION_PROMPT,
    { inlineData: { data: imageTop, mimeType: "image/jpeg" } },
    { inlineData: { data: imageSide, mimeType: "image/jpeg" } },
  ]);

  const json = JSON.parse(result.response.text());
  return Response.json(json);
}
```

## 6. 機能要件

### 6-1. トップ画面（`app/page.tsx`）

- タイトル：「ネイルチップサイズ測定ツール」
- 説明文：使い方の簡単な説明
- **推奨撮影条件の表示:**
  - 背景：白・無地
  - 照明：自然光または蛍光灯
  - 基準：**500円玉**を爪の横に置く
  - 距離：15〜20cm
  - 角度：真上・真横
- 対象形状：ショートオーバル（固定表示）
- 「はじめる」ボタン → `/capture` へ遷移

### 6-2. 撮影画面（`app/capture/page.tsx`）

- Step1（上から）→ Step2（横から）の2段階
- `getUserMedia` でアウトカメラ起動
- ガイド枠を画面中央にオーバーレイ表示
  - Step1：爪＋500円玉が横並びで収まる矩形枠
  - Step2：爪＋500円玉が横並びで収まる矩形枠（横向き用）
- 撮影ボタン押下 → `<canvas>` に描画 → base64取得
- 撮り直しボタンでリセット可能
- 両方撮影完了 → 「解析する」ボタンで結果画面へ遷移
- 画像はsessionStorageに一時保存して結果画面で参照

### 6-3. 結果画面（`app/result/page.tsx`）

- 読み込み時に `/api/estimate` へ画像2枚をPOST
- 結果受領までローディングオーバーレイ表示
- 受領後：
  - 推定幅・推定長さを表示
  - `matchSize()` で推奨サイズ算出・表示
  - サイズ表全10サイズを表形式で表示し、推奨サイズをハイライト
  - 「もう一度測る」ボタン → `/` へ遷移
- Gemini APIエラー時：エラーメッセージと再試行ボタン

### 6-4. ローディングオーバーレイ（`components/LoadingOverlay.tsx`）

- 全画面半透明背景
- スピナー＋「測定中です...」テキスト
- Gemini API応答まで表示

## 8. 推奨撮影条件（仕様として明示）

本ツールの精度は以下の条件下で保証される：

- 背景：白・無地
- 照明：自然光または蛍光灯（均一な明るさ）
- 基準物：500円玉を爪の横に配置（重ならない）
- 撮影距離：15〜20cm
- 角度：真上・真横から水平に撮影

**上記条件を満たさない入力による精度低下はサポート対象外。**

この旨をトップ画面と撮影画面の両方でユーザーに明示する。
